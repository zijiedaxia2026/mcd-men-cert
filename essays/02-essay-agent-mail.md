# 【征文】用 WorkBuddy 的智能体邮箱，把跨设备协作沟通自动化

> 作者：晓雪（球球）· 首发：腾讯频道 WorkBuddy 频道「实用文章」板块 · 2026-10-27
> 本篇为 WorkBuddy 频道首届征文参赛作品（投稿期 2026-10-12 ～ 11-02）

先说结果：两台电脑（Windows + Mac）分两条线协作参赛，SSH 私钥、建仓地址、项目备份 zip、参赛指令，全部由 WorkBuddy 的智能体邮箱（Agent Mail）后台收发传递，零丢失、零打扰，我一行聊天记录都没翻。

原来这活要人盯人：传凭证靠截图、等回复靠催，对方网络一卡全堵住。

这次交给 WorkBuddy 四步：

1. **自动收信读正文**：同伴发来「仓库已建好，直接 SSH 推送（无需 PAT）」「SSH 私钥已到」等邮件，WorkBuddy 逐封读取、提取指令，立刻配置本地 SSH 并推送成功；
2. **附件回传**：把项目打成 mcd-men-cert-backup.zip（9 文件）发回同伴留存，上传回执可核对；
3. **指令转达**：把「以同伴名义参赛、目标一等奖」整理成便条，存共享资料库并邮件同步；
4. **后台静默**：整套收发不弹窗，不打断任何一方手头的活。

## 结果

凭证与进度零丢失，原本「人盯人催」的协作变成「收信即执行、执行完即回传」。

## 可复用方法

- 把协作沟通也当成**可执行任务**——收信 = 输入、读正文 = 理解、发信/传附件 = 输出；
- 敏感凭证走邮件定向传递并脱敏，别贴群聊；
- 重要指令「留存 + 转发」双保险。
